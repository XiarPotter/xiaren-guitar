# Air Strings · 空气吉他

用摄像头识别手势，在浏览器里弹奏吉他和弦和旋律。不需要实体吉他、MIDI 设备或麦克风。

**在线弹奏：[https://xiarpotter.github.io/xiaren-guitar/](https://xiarpotter.github.io/xiaren-guitar/)**

> 建议使用桌面 Chrome 或 Edge。首次打开需加载约 17 MB 的识别运行库及模型，启动速度取决于网络。点击“开启摄像头”并允许摄像头权限后开始。

## 自选和弦库

展开页面中的“和弦库”，从29个常用和弦里勾选1–8个，按勾选顺序分配数字。使用左右箭头调整编号，点击“应用并保存”后，按钮、手势和快捷键会统一使用新映射。没有分配的数字不会触发其他和弦。

提供《旅行的意义》《鱼》《我不难过》片段三个快捷预设，填入后也需要点“应用并保存”。配置用 localStorage 保存在当前浏览器和网站地址下，不会上传，也不会跨设备同步；清除网站数据或退出无痕窗口可能丢失配置。浏览器拒绝保存时会显示提示。

下表是默认片段配置；**使用自选和弦后，以页面“当前映射”显示为准**。

## 音源切换

右侧“音源”可选择 **尼龙吉他采样（默认）**、**木吉他采样**、**原版合成拨弦**。首次选择采样音源时会加载约 0.7–1.4 MB 的 MP3，页面显示“采样已就绪”后可演奏。两套采样共约 2 MB，随站点托管，不依赖运行时的外部音源 CDN；加载失败会提示并退回合成音，可重新选择重试。

采样来自 [nbrosowsky/tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments)，音频为 CC BY 3.0；详见第三方资源说明。采样模式使用邻近录音移调，音色和实测音准仍需试听评估，不等同于专业多力度吉他音源。

## 怎么弹

默认使用“锁定和弦 + 张手弹奏”模式，左右均指**镜像画面中的左右区域**。

### 1. 左区：比数字选和弦

手掌朝向摄像头，在画面左区比数字，保持约 150 毫秒后锁定。实际响应还受到识别帧率影响。

| 手势 | 和弦 | 组成音 | 键盘 |
| --- | --- | --- | --- |
| 1 指，收起拇指 | C | C / E / G | 1 |
| 2 指，收起拇指 | Em | E / G / B | 2 |
| 3 指，收起拇指 | Gm7 | G / B♭ / D / F | 3 |
| 4 指，收起拇指 | A7 | A / C♯ / E / G | 4 |
| 五指张开 | Dm7 | D / F / A / C | 5 |
| 拇指＋小指，比“6” | Fm | F / A♭ / C | 6 |
| 拇指＋食指＋中指 | Am7 | A / C / E / G | 7 |
| 拇指＋食指，比“8” | D7 | D / F♯ / A / C | 8 |

当前为《我不难过》所选片段的专用 8 和弦映射，替换了早期版本的编号。7 使用上述三指伸展手形；其余手指收起，1–4 请收起拇指，避免与 7、8 混淆。选定后可以放下左区的手，和弦会保持；握拳不换和弦。

### 2. 右区：握拳 → 张开，弹奏一次

1. 在画面右区握拳，稍停一下，让识别器准备好。
2. 张开整只手，弹奏当前锁定的和弦。
3. 保持张开不会重复发声；重新握拳、再张开，继续弹奏。

例如，先在左区比“1”锁定 C，然后右区连续开合四次，就能弹四次 C。刚入镜时直接张开手不会自动发声，需要先握拳。

### 3. 旋律和伴奏

- **旋律模式：**默认模式下，单手上下移动选择 C 大调音阶，停稳自动弹奏。
- **自动分解和弦：**打开后，检测到演奏区域中的手时播放当前和弦的分解音；手离开后暂停后续音符。
- **速度、音量：**可在右侧面板调整，速度主要控制自动分解和弦。
- **进阶模式：**保留双手玩法，左区数字选和弦，右区开合弹奏；旋律使用上下选音与捏合触发。

## 没有摄像头也能玩

点击“先用键盘 / 鼠标试试”。

- 数字键 `1–8`：选择并弹奏对应和弦。
- `空格`：再次弹奏当前和弦。
- `A S D F G H J K`：弹奏 C、D、E、F、G、A、B、高音 C。
- 点击和弦卡片或“拨动琴弦”按钮也可发声。

## 隐私

- 只请求摄像头权限，**不请求麦克风**。
- 摄像头画面在浏览器本地由 MediaPipe 处理；应用代码不上传、保存或录制画面。
- 模型和运行库随网站一起托管，不需要运行时访问第三方模型 CDN。
- 页面字体会请求 Google Fonts；字体不可用时自动使用系统字体。
- GitHub Pages 仍会处理正常的网站资源访问请求。

## 本地运行

需要 Python 3。克隆仓库后，在项目根目录执行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。不要直接双击 `index.html`：摄像头需要 HTTPS 或 localhost，模块及模型也需要通过 HTTP 服务加载。

## 部署自己的版本

这是无需安装依赖、无需构建的静态站点。

1. Fork 本仓库。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. 选择 `main` 分支、`/ (root)` 文件夹并保存。
5. 等待 Pages 部署完成，使用 GitHub 显示的网站地址。

资源路径均为相对路径，支持 GitHub Pages 的项目子路径部署。README 顶部的体验链接指向原项目，Fork 后可改为自己的地址。

## 当前限制与排查

- **手势不稳定：**保持正面光照，手掌朝摄像头，完整露出手指；双手不要重叠，尽量待在各自区域内。
- **张开手掌识别不准：**五指自然分开，拇指不要贴住掌心。该识别器使用几何规则，不是经过专门训练的数字分类器，个别角度可能误判。
- **张手不响：**先在画面右区握拳再张开；重新进入画面也需要先握拳。检查音量或先点“拨动琴弦”。
- **摄像头打不开：**检查浏览器和系统的摄像头权限，以及摄像头是否被其他程序占用。页面会显示启动错误。
- **模型加载慢：**首次需要下载模型和 WASM；等待加载完成，或先用键盘试玩。
- **音色与音准：**八个和弦的组成音按标准吉他指法配置，目标频率使用 A4=440 Hz 的十二平均律。默认使用吉他采样并以播放速率移调；原版合成拨弦仍可选择，其延迟线取整和滤波可能带来细微偏差。两者尚未完成音频实测校准。它适合手势音乐实验，不能替代专业乐器或调音器。
- 暂无录音、歌词同步、歌曲自动跟弹及账户系统。
